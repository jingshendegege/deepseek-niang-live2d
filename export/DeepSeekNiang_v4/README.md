本目录包含 14 页贴图、38 个表情条目、物理、动作及 VTube Studio 配置。Git 版本不含大体积的 `DeepSeekNiang.moc3` 与 `DeepSeekNiang.cmo3`；完整 ZIP 从仓库 Releases 下载，未发布时请向维护者取得。

完整 ZIP 解压后，可将整个 `DeepSeekNiang_v4` 文件夹复制到 VTube Studio 的 `Live2DModels` 目录。网页使用时把本文件夹放在仓库 `export/` 下，依赖安装步骤见仓库 README。

Cubism 编辑工程仅保留根目录的一份 `.cmo3`。`Cubism/DeepSeekNiang.can3` 是动画工程，若编辑器提示旧工程引用，请手动重新关联根目录的 `DeepSeekNiang.cmo3`；不影响模型运行。
